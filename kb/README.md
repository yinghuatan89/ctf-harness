# Knowledge base (kb/)

This folder is your **writeup corpus**. Drop `*.md` / `*.txt` files here -
writeups you collect, cheatsheets you write, organiser-specific tricks - and
the harness automatically injects the most relevant paragraphs into the
supervisor/strategist and lane prompts (keyword overlap with the challenge
recon).

Competition tip: before an event, collect writeups of that organiser's past
events into this folder - the team gets measurably faster on "same-flavour"
challenges.

Optional tag line at the top of a file:

```
tags: sqli, mysql, auth-bypass
```
